# Support

Open Chat Reviewer is alpha, volunteer-maintained software.

- Ask setup and usage questions in [GitHub Discussions](https://github.com/MiddleDistances/23-open-chat-reviewer/discussions/categories/q-a).
- Report reproducible bugs through the [bug report form](https://github.com/MiddleDistances/23-open-chat-reviewer/issues/new?template=bug_report.yml).
- Propose scoped improvements through the [feature request form](https://github.com/MiddleDistances/23-open-chat-reviewer/issues/new?template=feature_request.yml).
- Report vulnerabilities, credentials, private chat material, and other sensitive matters
  through [private vulnerability reporting](https://github.com/MiddleDistances/23-open-chat-reviewer/security/advisories/new).

Questions and reports are handled on a best-effort basis. Never post raw conversations,
database URLs, API keys, personal filesystem paths, or unredacted logs publicly.
